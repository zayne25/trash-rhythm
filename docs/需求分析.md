# 需求分析 —— 《垃圾分类大作战》（节奏音游）

## 1. 项目背景与目标

垃圾分类是环保教育的重要主题，但传统的"拖拽投桶"玩法缺乏紧张感。本项目把垃圾分类套上**音乐节奏游戏的判定机制**：垃圾随节拍落下，玩家必须在判定线上精准操作。目标是在娱乐中巩固四分类知识，并探索"AI 辅助下的三人协作开发"。

## 2. 目标用户

- 课程评审师生（演示对象）；
- 中小学生及环保科普场景（潜在用户）。

## 3. 功能需求

| 编号 | 功能 | 说明 | Owner |
|---|---|---|---|
| F1 | 主菜单 | 关卡选择、玩法说明、最高分展示 | 丙 |
| F2 | 音频引擎 | WebAudio 程序化 BGM + 判定音效 + 唯一时间源 | 甲 |
| F3 | 谱面生成 | 按 BPM 节拍网格从垃圾池生成音符 | 甲 |
| F4 | 判定系统 | Perfect/Good/Bad/Miss/WrongBin 五档，连击倍率、生命值 | 甲 |
| F5 | 渲染 | Canvas 绘制下落音符、判定线、四个分类桶 | 乙 |
| F6 | 特效 | 判定圆环/文字/粒子、震屏、桶按下高亮 | 乙 |
| F7 | 输入 | 键盘 D/F/J/K + 鼠标点击 + 触屏，三端统一 | 乙 |
| F8 | UI/HUD | 分数、连击、生命、进度条、知识点弹窗、结算页 | 丙 |
| F9 | 数据 | ≥40 条垃圾（四分类均衡、含知识点）、3 关配置 | 丙 |
| F10 | 持久化 | 各关最高分（localStorage） | 丙 |

## 4. 非功能需求

| 类别 | 指标 |
|---|---|
| 音画同步 | 连玩 60 秒判定时钟漂移 ≤ 20ms（以 AudioContext.currentTime 为唯一时间源） |
| 性能 | 60 FPS，Canvas 逻辑分辨率 960×640 |
| 适配 | 桌面（1280×720+）与手机竖屏均可游玩 |
| 版权 | 音频全部程序化合成，零第三方素材、零第三方库 |
| 可复现 | 零构建，clone 后双击 index.html 即玩 |
| 可部署 | 纯静态，可直接托管 GitHub Pages |

## 5. 数据需求

- 四分类：可回收物 / 有害垃圾 / 厨余垃圾 / 其他垃圾；
- 每条数据：名称、分类、难度(1~3)、一句知识点（按错桶时弹出，承担科普功能）；
- 难度池：第 N 关只从 `diff ≤ N` 的垃圾中抽取。

## 6. 交付物清单

1. 可运行的网页游戏（本仓库）；
2. 部署上线链接（GitHub Pages，见 README）；

4. 3 分钟演示视频（含"按错桶弹知识点""连击特效""手机端"三个演示点）。
