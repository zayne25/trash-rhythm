# 部署方案 —— 课堂演示场景（垃圾分类大作战）

> 阶段五交付文档（丙）。目的：为课堂演示提供明确、可执行、可验证的部署与交付流程。
> 项目形态：纯静态 HTML/CSS/JS，无构建步骤，托管于 Gitee。

## 1. 目标与验收口径

- 课堂现场通过浏览器完整演示：首页 → 关卡选择 → 游玩（D/F/J/K 判定）→ 结算
  （判定分布条 / 准确率双环 / 得分对比条 / 错题回顾）→ 知识库 / 设置。
- 演示全程不依赖现场网络也能运行（离线兜底，见 §2 备通道）。
- §5 交付物清单全部就绪，任何人拿到链接/离线包都能复现演示。

## 2. 部署方式（主备双通道）

  `https://pan-aaa.gitee.io/trash-rhythm/` 一直是 404，放弃该通道。
- 若未来官方恢复开通，步骤仍是：仓库 → 服务 → Gitee Pages → 分支 master → 启动。

### 公网主通道：GitHub Pages（✅ 2026-11-24 已开通并验证）
- **链接地址：`https://zayne25.github.io/trash-rhythm/`**（实测 HTTP 200，
  buildTag `v3-20261124d`、开局 `scene=playing`、44 张图标全部加载、控制台无脚本错误）。
- 仓库：`https://github.com/zayne25/trash-rhythm`（默认分支 `main`，Pages 源 = main / root）。
- 更新流程：本地 `master` 有新提交后推送到 GitHub 的 `main`
  （`git push github-https master:main`）；若 `github.com:443` 被网络重置，
  可用 Git Data API 上传（blob → tree → commit → ref，走 `api.github.com`）。
- 首次部署备注：空仓库须先用 Contents API 建首个提交激活；Pages 开通在网页端
  Settings → Pages → Deploy from a branch → main → Save（token 权限不够时）。

### 局域网链接（手机 / 电脑通用，无需公网、无需实名）
- 演示电脑启动本地服务（离线包里双击 `START.bat`，或仓库里 `node release/serve-lan.js`），
  默认监听 `0.0.0.0:8000`。
- 手机与电脑连**同一 Wi-Fi**，手机浏览器打开 `http://<演示电脑局域网IP>:8000/index.html`。
- 查 IP：Windows 执行 `ipconfig`，取「无线局域网适配器 WLAN」的 IPv4 地址
  （如 `192.168.1.23`；VMware 虚拟网卡的 192.168.x.1 不是真实 IP）。
- 若打不开，多为演示电脑防火墙拦截，放行 python/node 的入站连接即可；此方案不依赖外网。
- 服务停止：Ctrl+C 或结束对应 node/python 进程。

### 通道 1.5：可选公网链接（如课堂要求"扫码即开"，需要额外账号）
- 免费静态托管均需注册对应平台账号并实名/登录，任选其一：
  - **GitHub Pages**：仓库推送至 GitHub → Settings → Pages → 选 master 分支；
  - **Cloudflare Pages / Netlify / Vercel**：连仓库自动部署；
  - Gitee 服务菜单里的「腾讯云托管」也可（需腾讯云账号与实名）。
- 注意国内访问稳定性不如局域网，课堂演示仍以局域网链接为主、公网为辅。

### 备通道：离线本地包
- 仓库打包为 zip（含 `index.html`、`css/`、`js/`、`data/`、`assets/`、`docs/`、启动脚本）。
- 现场任选其一启动静态服务：
  - `python -m http.server 8000`（或双击包内 `START.bat`）
  - `npx serve .`
- 浏览器访问 `http://localhost:8000`。
- **不要双击 index.html 直接用 file:// 打开**：部分浏览器限制本地脚本行为，作为最后兜底。

### 分享通道：单文件版（微信/QQ 直接发文件，零账号零依赖）
- 产物：`release/trash-rhythm-single.html`（约 0.85MB）。
- 由 `node release/build-single.js` 生成：CSS/JS/data 全部内联，44 张图标转 base64
  data URI，单文件无任何外部请求。
- 发给别人：微信/QQ 发送该文件 → 对方下载 → Android 用浏览器打开即玩
  （微信内可选「用其他应用打开 → 浏览器」）；电脑双击用浏览器打开。
- 已实测：`__buildTag = single-v3-20261124b`、开局 `scene=playing`、图标 data URI
  加载成功、知识库 44 卡正常、暂停/返回可用。
- iPhone 限制：iOS 浏览器无法直接打开本地 HTML 文件，iPhone 用户请用局域网链接
  （同 Wi-Fi）或公网托管链接。
- 重新生成：改完代码后跑一次 `node release/build-single.js`，并核对版本标注。

### 兜底：录屏视频
- 演示前一天录制一局完整游玩视频（含结算页全要素），现场主备通道都失败时播放。

## 3. 演示环境要求

| 项 | 要求 |
|---|---|
| 硬件 | 教室电脑或自带笔记本 + 投影（HDMI） |
| 分辨率 | 电脑 ≥1280×720；手机 390×844 已实测无横向溢出（首页/关卡/游戏/结算/弹窗） |
| 浏览器 | 电脑 Edge / Chrome 最新版；手机 Safari / Chrome 均可 |
| 网络 | 主通道需访问 gitee.com；受限时切局域网链接或离线包 |
| 输入 | 电脑 D/F/J/K 四键；手机/平板**点按画面下方分类桶**分拣（`pointerdown` 已兼容触屏，坐标按 960×640 逻辑分辨率换算） |
| 触屏文案 | `@media (pointer: coarse)` 下首页提示改为「👆 点按画面下方的分类桶即可分拣」；局内提示改「👆 点按下方分类桶进行分拣」并在开局 6 秒后自动收起，不再显示误导性的键盘提示 |

## 4. 演示前检查清单（开课前 10 分钟）

1. 打开首页：四入口齐全、图标加载完整、控制台无红错（favicon 404 可忽略）。
2. 设置弹窗：**重置数据**（清最高分/收藏/设置，从零演示）；音量、BGM 开关调好。
3. 试玩 30 秒：进"环保新人"，验证判定、音效、HUD 暂停按钮、本局用时。
4. 关闭无关标签页与系统通知，避免抢焦点。
5. 投影分辨率下过一遍结算页：环形进度环、判定分布条、得分对比条显示正常。

## 7. 风险与预案

| 风险 | 预案 |
|---|---|
| 手机连不上局域网链接 | 核对同一 Wi-Fi 与 IP（排除 VMware 虚拟网卡）；防火墙放行 node/python 入站；30 秒内切离线包 |
| 教室电脑无 Python/Node | 离线包 `START.bat` 三级回退；都无则用便携版或手机扫码公网链接（若有） |
| 浏览器缓存旧版 | `?v=` 版本号机制 + Ctrl+F5 + 核对 `__buildTag`（当前 `v3-20261124b`） |
| 键盘焦点丢失（已知 issue，iframe/点按后） | 点击页面任意处再按键；手机端无此问题（点按分拣） |
| 演示中数据脏了 | 设置 → 重置数据（二次确认），约 30 秒恢复出厂 |
| 双人同机演示误触 | 演示前重置数据，结算页"返回菜单"可随时退出 |
